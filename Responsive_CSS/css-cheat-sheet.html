Responsive CSS Cheat Sheet

Quick reference guide for responsive design concepts

CSS Filters

Apply visual effects to elements

filter: blur(5px);
filter: grayscale(100%);
filter: brightness(150%);
filter: contrast(200%);

Media Queries

Apply styles based on screen size

@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}

Responsive Design

Create layouts that adapt to any screen

display: flex;
flex-wrap: wrap;
grid-template-columns:
  repeat(auto-fit, minmax(200px, 1fr));

Typography

Fluid font sizes with clamp()

font-size: clamp(1rem, 2vw, 1.5rem);
line-height: 1.6;
letter-spacing: 0.05em;

Flexbox Layout

One-dimensional flexible layouts

display: flex;
justify-content: space-between;
align-items: center;
gap: 1rem;

Grid Layout

Two-dimensional grid-based layouts

display: grid;
grid-template-columns: repeat(3, 1fr);
grid-gap: 2rem;
grid-auto-rows: minmax(100px, auto);

Transitions

Smooth property changes over time

transition: all 0.3s ease;
transition-property: transform;
transition-duration: 0.5s;

Transforms

Modify element position and appearance

transform: translateY(-10px);
transform: scale(1.1);
transform: rotate(45deg);

Animations

Create keyframe-based animations

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
animation: fadeIn 1s ease-in;
