Understanding the difference between content-box and border-box

Default: content-box

Width: 300px

Padding: 20px

Border: 5px

Total Width: 350px

(300 + 40 + 10 = 350px)

How it works:

With box-sizing: content-box (default), the width and height only apply to the content. Padding and border are added outside, increasing the total size.

Modern: border-box

Width: 300px

Padding: 20px

Border: 5px

Total Width: 300px

(includes padding & border)

How it works:

With box-sizing: border-box, the width and height include padding and border. The content area shrinks to accommodate them, keeping the total size constant.

Key Differences

🎯 Predictability

border-box makes sizing more predictable and easier to calculate

📐 Layout Control

You don't need to subtract padding and border from your width calculations

✅ Best Practice

Most modern CSS frameworks use border-box as the default
