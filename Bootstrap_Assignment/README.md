# Bootstrap Assignment 10 - Complete Solutions

This folder contains all 10 Bootstrap 5 assignments with separate HTML and CSS files for each question.

## 📋 Assignment List

### Q1: Company Landing Page
**Files:** `company-landing.html`, `company-landing.css`
- Full-width navbar with hamburger menu
- Hero section with gradient background
- Bootstrap grid system (`.container`, `.row`, `.col`)
- Feature boxes with responsive layout
- Stats section

### Q2: Personal Portfolio Basics
**Files:** `personal-portfolio.html`, `personal-portfolio.css`
- Bootstrap utilities (spacing, text, background)
- Profile image (`.img-fluid`, `.rounded-circle`)
- Buttons with hover effects
- Contact form with `.form-control`
- Skills section

### Q3: Product Catalog
**Files:** `product-catalog.html`, `product-catalog.css`
- Responsive grid: 4 columns (desktop) → 2 columns (tablet) → 1 column (mobile)
- Product cards with images and "Add to Cart" buttons
- `.shadow-sm` and hover transitions
- Uses `.col-md-3`, `.col-sm-6`, `.col-12`

### Q4: Restaurant Menu Page
**Files:** `restaurant-menu.html`, `restaurant-menu.css`
- Bootstrap table (`.table-striped`, `.table-hover`)
- List group for Chef's Specials
- Food image with `.img-fluid`
- Typography with `.text-center` and `.lead`
- Menu items with categories and prices

### Q5: Custom Themed Blog
**Files:** `themed-blog.html`, `themed-blog.css`
- Custom CSS variables (`--bs-primary`, `--bs-font-sans-serif`)
- Google Font integration (Poppins)
- Themed buttons, headings, and cards
- Gradient backgrounds
- Blog post cards

### Q6: Notifications Dashboard
**Files:** `notifications-dashboard.html`, `notifications-dashboard.css`
- Success, info, and danger alerts
- Dismissible alert (`.alert-dismissible`)
- Summary well with stats
- Card component for grouping
- Contextual color usage

### Q7: Task Tracker
**Files:** `task-tracker.html`, `task-tracker.css`
- Task list with `.list-group`
- Badges for priority (High, Medium, Low)
- Badge counter in header

- Task statistics section

### Q8: Pricing Plans
**Files:** `pricing-plans.html`, `pricing-plans.css`
- Three cards side-by-side (`.col-md-4`)
- Highlighted "Pro" plan (`.bg-primary`, `.text-white`)
- Hover effects with `.shadow-lg`
- Feature comparison list
- Responsive layout

### Q9: Blog Pagination
**Files:** `blog-pagination.html`, `blog-pagination.css`
- Bootstrap pagination (`.pagination`)
- Centered with `.justify-content-center`
- Previous/Next buttons
- Pager with "Older/Newer Posts"
- Multiple pagination styles

### Q10: Travel Agency Showcase
**Files:** `travel-showcase.html`, `travel-showcase.css`
- Bootstrap Carousel with 3 slides
- Custom time intervals (`data-bs-interval`)
- Animated progress bar (`.progress-bar-striped`, `.progress-bar-animated`)
- Carousel captions with booking buttons
- Contact footer
